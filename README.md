# מסע מילים ביפן

**Japan Word Journey · UNIT 1** — אתר לתרגול אוצר מילים באנגלית בנושא All About Japan. זהו פרויקט עצמאי, המבוסס על קובץ ה־HTML שסיפק המשתמש; הוא אינו חלק מאתר LearningEnglish ואינו מחליף את UNIT 2 שלו.

האתר הציבורי: [מסע מילים ביפן](https://japan-word-journey-dor.attiasyaron.chatgpt.site). כל מי שיש לו את הקישור יכול להיכנס ישירות, ללא חשבון, מייל, סיסמה או הזדהות.

מסמך ההחלטות וההגדרות עודכן ב־27 בנובמבר 2026. הגרסה האחרונה נפרסה ב־26 בנובמבר 2026 לאחר QA, כגרסת Sites מספר 3. קוד הגרסה שנפרסה נמצא ב־commit `8155e557d16caa542a7024a0d9f01c6d4fa6ae42`; עדכון התיעוד אינו משנה את קוד האפליקציה.

## הפעלה

הריצו `node preview.cjs` בתיקייה זו ופתחו http://127.0.0.1:4173 . השרת מאזין במחשב המקומי בלבד ומגיש רק את האתר. במקרה של חסימת רשת בסביבת הרצה מוגבלת יש להריץ את השרת בסביבה עם גישה ל־loopback.

`index.html` הוא האתר המלא, ללא תלויות חיצוניות או שלב בנייה. `original.html` הוא עותק המקור ללא שינוי. `build-site.cjs` משחזר את ההתאמות מתוך עותק המקור; עריכות עתידיות צריכות להתבצע בו לפני הרצה חוזרת כדי שלא להידרס. `node test-content.cjs` בודק תוכן, תחביר, שמירה ושימור חומרי התרגול המקוריים.

- בגרסה שפורסמה יש 8 תחנות, מהן 7 המזכות בכוכבים (עד 21). הוסרו משחק הזיכרון, איש תלוי ואתגר המהירות, כולל הקוד של הפעילויות האלה. האיורים ומפתח השמירה `jp-vocab` נשמרו; צבעי הממשק הותאמו ל־UNIT 2. נקודות וכוכבי התחנות שנותרו נשמרים; כוכבי התחנות שהוסרו אינם נספרים.
- נוספו 22 מילים בשתי קבוצות Classroom; בסך הכול 100 מילים. מסנני הקבוצות פועלים ברשימת המילים ובכרטיסיות בלבד, בהתאם למקור.
- המילים החדשות נכללות בתרגילים המשתמשים במאגר הכללי. מאגר 26 משפטי ההשלמה עודכן: לכל משפט ארבע אפשרויות נבחרות מתוך מאגר 100 המילים, עם תשובה ברורה אחת. גם שאלות המשפטים במבחן המסכם משתמשות באותו מאגר ואותן אפשרויות. מאגרי התמונות, המיון והקריאה נשמרו.
- ההוראות, הניווט והמשוב המילולי בעברית; חומר הלימוד באנגלית נשמר.
- נוספו התאמות לנייד, קרדיט וחלון אודות/פרטיות/תנאים. הנתונים מקומיים ללא סנכרון. כפתור צלילי המשחק שולט באפקטים, בנפרד מהקראת מילים.

## שמירה, ניקוד ושמע

- שמירה מקומית תחת `localStorage` במפתח `jp-vocab`, עם `pts` ו־`stars` לפי מזהי פעילויות. אין שרת משתמשים, חשבון או סנכרון בין מכשירים.
- נשמרות נקודות וכמות הכוכבים הטובה ביותר בכל פעילות, עד שלושה כוכבים לפעילות ושבע פעילויות מזכות. חזרה על פעילות אינה מפחיתה הישג קודם.
- השמירה הישנה ממשיכה לעבוד: נקודות וכוכבי פעילויות שנותרו נשמרים, וכוכבי פעילויות שהוסרו אינם נכללים בתקרה או בסכום. נתונים פגומים נבדקים בעת טעינה.
- לא משחזרים שאלה פעילה או סדר תשובות לאחר רענון; פתיחת פעילות מתחילה סבב חדש. זו החלטה מכוונת לשמור על מנגנון הקובץ המקורי ולצמצם שינויי קוד.
- ציוני סבב מוצגים במילים, למשל ״5 תשובות נכונות מתוך 6״, כדי להימנע מהיפוך מספרים ב־RTL. אלה מדדי תרגול, לא ציון בית־ספרי ולא הוכחה לשליטה בחומר.
- מתג הרמקול שולט בצלילי המשחק דרך Web Audio. הקראת המילים היא פעולה נפרדת המשתמשת ב־Speech Synthesis של הדפדפן/המכשיר באנגלית, במהירות 0.85. חוסר זמינות מוצג בעברית ואינו חוסם תרגול; יציאה מפעילות מבטלת הקראה פעילה.
- אין מפתח API לשירות דיבור. זמינות ואיכות הקול תלויות במכשיר ובדפדפן; חלק מהקולות עשויים להסתמך על שירות חיצוני של ספק המערכת.

## מבנה הפרויקט ובנייה

אתר סטטי ללא פריימוורק או תלויות ריצה. CSS, JavaScript ואיורי SVG כלולים בקובץ האתר.

| קובץ | תפקיד |
|---|---|
| `original.html` | עותק המקור שסיפק המשתמש; נשמר ללא שינוי |
| `build-site.cjs` | המקור להתאמות; קורא את המקור ומייצר מחדש את `index.html` |
| `index.html` | האתר שנוצר, המשמש גם לתצוגה מקומית |
| `dist/index.html` | עותק ההפצה, זהה ל־`index.html` |
| `preview.cjs` | שרת תצוגה מקומי בפורט 4173, המגיש את האתר בלבד |
| `.openai/hosting.json` | זהות אתר Sites והגדרת הפצה סטטית מתיקיית `dist` |
| `mockups/` | שתי חלופות התכנון ההיסטוריות; אינן פעילות באתר הציבורי |
| `tests/` | בדיקות רגרסיה, דוחות וראיות |

יש לערוך את `build-site.cjs` ולא להסתפק בעריכת הקובץ שנוצר, כדי שהבנייה הבאה לא תדרוס את השינוי.

```powershell
node build-site.cjs
Copy-Item -LiteralPath index.html -Destination dist/index.html
node test-content.cjs
node tests/test-uat-high.cjs
node tests/test-compact-home.cjs
node preview.cjs
```

לאחר בנייה יש לבדוק שזהות הבתים בין קובצי האתר נשמרה. חתימת SHA-256 של המקור הבלתי משתנה היא `131fbe27673973ddec22ad504de34f89409fa3a3efad4aa498514d7174dc0095`; חתימת האתר של גרסה 3 היא `58d78246b0fc3783c690f081848240cf7ad405de5f8466bb42f1b89859f1bb8a`.

## בדיקות, סקילים והחלטות UAT

הוחלו עקרונות מ־`sites:sites`, מ־`game-ui-frontend` ומ־`app-about-credits`. `computer-use` שימש להרצות דפדפן; `chief-of-staff` שימש לתיאום סוכנים כשזמינים, ובמגבלת שימוש העבודה הושלמה ישירות. `14yearsold-uat` שימש להדמיית בדיקה מנקודת מבט של תלמיד ולדוח החלטות, ולא לבדיקה עם תלמיד אמיתי. בוצעה גם סקירה דיפרנציאלית ממוקדת; אין טענה לביקורת אבטחה מלאה.

הממצאים בחשיבות גבוהה אושרו ותוקנו: **UAT-01** — הקשר ברור במשפטים; **UAT-02** — תוצאות ללא היפוך מספרים; **UAT-04** — תיקון מילולי של תשובות במחסן ובקריאה והתקדמות יזומה לסיכום. החלטת ארבע האפשרויות הרחיבה לאחר מכן את עדכון המשפטים לכל 26 הפריטים.

ממצאים בחשיבות בינונית לא אושרו כסבב תיקון נפרד: UAT-03 עסק בהודעת מילוי חסר, וחלק ממשוב המחסן השתנה במסגרת UAT-04; לא נטען אימות עצמאי מלא שלו. UAT-05 עסק בנגישות קלפי זיכרון ואינו חל לאחר הסרת הפעילות. UAT-06, השלמת בדיקות מכשירים ונגישות, נשאר מגבלת כיסוי.
